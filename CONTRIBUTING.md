# Contributing Guidelines

Thanks for contributing to this profile repository.

## Scope

Contributions should improve documentation quality, accessibility, automation, or repository hygiene.

## Before You Submit

1. Keep changes focused and small.
2. Update README sections with clear, factual content.
3. Verify links and formatting.
4. Avoid adding sensitive information.

## Pull Requests

- Use descriptive commit messages.
- Explain what changed and why.
- Reference related issues when applicable.
